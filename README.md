# GridPath Prototype

GridPath is a decision-support workspace for early infrastructure site screening. It combines a live map, satellite layer, candidate-area overlays, public infrastructure checks, location search, project inputs, financial screening, and jurisdiction-aware review prompts.

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

This tool uses public data for preliminary screening only. It is not a legal, engineering, land-title, permitting, grid-capacity, or investment determination.
